# Portfolio Website

## Overview
This is a personal portfolio website built with HTML, CSS, and JavaScript. It features a modern, dark-themed design inspired by morsecodemedia.com, and showcases your projects, biography, and contact information.

## Features
- **Multi-page structure:**
  - Main page (`index.html`)
  - About page (`about.html`)
  - Projects page (`projects.html`)
  - Project 1 page (`project1.html`)
  - Project 2 page (`project2.html`)
- **Navigation:** Fixed header with smooth scrolling and links to all sections/pages.
- **Hero section:** Includes your name, title, and photo.
- **Project galleries:** Each project page features a description, image gallery, captions, and (for Project 1) a YouTube video link.
- **Contact section:** Displays your email (`sabbasov26376@ada.edu.az`) and links to CodeAcademy and GitHub.
- **Footer:** Consistent footer with all contact links and copyright.
- **Responsive design:** Works well on desktop and mobile.
- **Modern styling:** Card layouts, gradients, and clean typography.

## Project Details
- **Project 1:** Logic gate construction with team members (XOR, NOR, AND, OR, NOT gates). Includes a YouTube video demonstration.
- **Project 2:** Volunteering at a school in poor conditions, providing computers and internet for children to study.

## How to Run Locally
1. Clone the repository:
	```sh
	git clone https://github.com/abbasovsaleh/portfolio.git
	```
2. Open the folder in VS Code or your preferred editor.
3. Start a local server (e.g., Python):
	```sh
	python3 -m http.server
	```
4. Visit `http://localhost:8000` in your browser.

## Deployment
To deploy on GitHub Pages:
1. Push all changes to the `main` branch.
2. In your GitHub repo settings, set Pages source to `/ (root)` and branch to `main`.
3. Your site will be live at `https://abbasovsaleh.github.io/portfolio/`.
