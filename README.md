# Personal Portfolio Website

A modern, responsive portfolio website showcasing my work, skills, and professional experience.

## 🌐 Live Demo

This portfolio is deployed on GitHub Pages and can be accessed at: `https://<username>.github.io/portfolio/`

Replace `<username>` with your GitHub username.

## ✨ Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Multiple Pages**: 
  - Home: Welcome page with an overview
  - About: Information about skills and background
  - Projects: Showcase of recent work and projects
  - Contact: Contact form and social media links
- **Easy Navigation**: Intuitive menu with mobile hamburger menu support

## 🚀 Deployment

This website is automatically deployed to GitHub Pages using GitHub Actions. Any push to the `main` branch will trigger a new deployment.

### Manual Deployment Setup

If you want to set up GitHub Pages manually:

1. Go to your repository settings
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select "GitHub Actions"
4. The workflow will automatically deploy your site

## 🎨 Customization

To customize this portfolio for your own use:

1. Update the content in each HTML file with your own information
2. Modify the colors in `styles.css` by changing the CSS variables in `:root`
3. Replace project examples with your actual projects
4. Update contact information in `contact.html`
5. Customize the social media links
